## 1. Intent & Problem Framing

Vấn đề gốc nằm ở thứ tự pipeline. `s05_director_plan` sinh motion plan trước khi `s09_voice_tts` có timestamp của Whisper. Vì vậy plan v6 không được chứa thời gian tuyệt đối. Nó chỉ neo các beat vào cụm từ trong script. Timeline thực (frame) được resolve sau s09, tại cửa vào `s10_render`. Nếu bỏ qua điểm này, hình sẽ trôi khỏi giọng đọc.

Bốn thành phần kỹ thuật:

| Thành phần | Bản chất | Ràng buộc cứng |
|---|---|---|
| Tọa độ 2D chuẩn hóa | `x,y ∈ [0,1]`, gốc top-left. Kích thước chuẩn hóa theo chiều cao composition | Một plan phải render đúng ở cả 16:9 và 9:16 |
| Snap-Stop | Chuyển động easing-out, quantize "on twos", dừng hẳn ở frame cuối | Độ dài nằm trong `[ceil(0.4·fps), floor(0.6·fps)]` frame. Không drift sau khi dừng |
| Causal Docking + Pop Box | Element con neo vào bbox của element cha. Pop box scale `0 → 1.06 → 1` | Đồ thị dock phải là DAG. Con không được vào trước cha |
| Massive Living Hold | Hold co giãn lấp khoảng giữa các word anchor của Whisper, có micro-motion seeded | Tổng frame bằng đúng `ceil((audio_end + tail)·fps)`, không tích lũy sai số làm tròn |

Trade-off chính:
- Gap giữa hai anchor ngắn hơn `snap_min + min_hold` thì có 3 lựa chọn: kéo dài snap ra ngoài bounds, trễ beat sau, hoặc gộp hai beat. Chọn gộp (coalesce) và cho vào cùng frame của beat trước. Lý do: hình đi trước tiếng vài frame vẫn chấp nhận được, còn hình đi sau tiếng thì không. Mỗi lần gộp phải phát warning để s06 thấy.
- Đo text cho bbox: Python không đo chính xác được font. Bbox vì vậy được khai báo dạng `max box` trong plan. Remotion fit text bên trong bằng `@remotion/layout-utils` (`fitText`/`measureText`) sau khi font load xong qua `delayRender`.
- Làm tròn frame: tính boundary từ thời gian tuyệt đối (`round(t·fps)`), không cộng dồn duration. Cách này chặn drift ở video dài.

Hai khái niệm cần chốt định nghĩa. Tôi tự gán, bạn sửa nếu khác ý:
- Three-Way Sync: Local IDE ⇄ Git origin ⇄ VPS `/root/video_factory` cùng commit SHA, working tree sạch ở cả ba. Thêm một lớp parity schema: JSON Schema ⇄ Pydantic ⇄ TS/Zod.

Lõi của resolver:

```python
import math

SNAP_MIN_S, SNAP_MAX_S = 0.4, 0.6

def snap_frames(snap_s: float, fps: int) -> int:
    """Clamp độ dài snap vào [ceil(0.4*fps), floor(0.6*fps)] frame."""
    lo, hi = math.ceil(SNAP_MIN_S * fps), math.floor(SNAP_MAX_S * fps)
    return max(lo, min(hi, round(snap_s * fps)))

def beat_start_frames(anchor_times_s: list[float], fps: int, min_gap_frames: int):
    """
    Tính boundary từ thời gian tuyệt đối để không tích lũy sai số làm tròn.
    Gap quá ngắn thì gộp beat sau vào frame của beat trước (hình đi trước tiếng, không đi sau).
    Trả về (danh sách frame bắt đầu theo beat, danh sách warning).
    """
    starts, warnings = [], []
    for i, t in enumerate(anchor_times_s):
        f = round(t * fps)
        if starts and f - starts[-1] < min_gap_frames:
            warnings.append({"code": "BEAT_COALESCED", "beat": i, "into": i - 1})
            f = starts[-1]
        starts.append(f)
    return starts, warnings

def total_frames(audio_end_s: float, tail_s: float, fps: int) -> int:
    return math.ceil((audio_end_s + tail_s) * fps)
```

Với `min_gap_frames = snap_frames_min + min_hold_frames`, đề xuất `min_hold_frames = 4`. Hold của mỗi element kéo dài từ `enter_end` đến `exit_start`. Vì `exit_start` được neo vào beat tiếp theo hoặc `total_frames`, hold tự co giãn theo giọng đọc.

Lõi snap-stop:

```ts
import {interpolate, Easing} from 'remotion';

/**
 * Tiến độ 0..1 của chuyển động snap.
 * Hard stop: kiểm tra trên frame thô trước khi quantize, để duration lẻ vẫn chạm đúng 1 tại frame cuối.
 */
export const snapProgress = (
  frame: number,
  startFrame: number,
  durationFrames: number,
  onTwos = true,
): number => {
  const local = frame - startFrame;
  if (local <= 0) return 0;
  if (local >= durationFrames) return 1;
  const q = onTwos ? Math.floor(local / 2) * 2 : local;
  return interpolate(q, [0, durationFrames], [0, 1], {
    easing: Easing.out(Easing.exp),
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
  });
};
```

## 6. Code Map GPS Gating (Rule 138)

Chưa query thì không có tọa độ, nên đây là cổng chặn: T0 phải xong trước mọi task sửa file. Tôi chưa biết cấu trúc key của `codemap.json`, nên dùng một lệnh tìm đệ quy:

```bash
python - <<'EOF'
import json

TERMS = ("s05", "s06", "s09", "s10", "director", "whisper", "remotion", "render", "Root", "composition", "fps")
cm = json.load(open(".codemap/codemap.json", encoding="utf-8"))

def walk(node, path="$"):
    """In mọi path JSON có key hoặc giá trị chứa một trong các TERMS."""
    if isinstance(node, dict):
        for k, v in node.items():
            p = f"{path}.{k}"
            if any(t.lower() in k.lower() for t in TERMS):
                print(p, "=>", json.dumps(v, ensure_ascii=False)[:200])
            walk(v, p)
    elif isinstance(node, list):
        for i, v in enumerate(node):
            walk(v, f"{path}[{i}]")
    elif isinstance(node, str) and any(t.lower() in node.lower() for t in TERMS):
        print(path, "=>", node[:200])

walk(cm)
EOF
```
